# Wig Laundry & Hair Maintenance — V2

A responsive business website concept for a wig-care service, built to demonstrate practical front-end development, responsive design, JavaScript interactions and GitHub Pages deployment.

## 🌐 Live Demo

[View Live Website](https://nqobile-nkenjane.github.io/Wig-laundry-website/)

## ✨ Features

- Responsive mobile navigation
- Wig-care service and package sections
- Service and package booking flow
- WhatsApp booking and enquiry integration
- Product enquiry buttons
- Interactive FAQ section
- Before-and-after section
- Gallery with lightbox interaction
- Responsive design for mobile, tablet and desktop
- Accessibility features including labels, focus states and skip link
- SEO-friendly metadata
- Lazy-loaded images
- Reduced-motion support

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design
- GitHub Pages
